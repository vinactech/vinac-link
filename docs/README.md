# VINAC Link documentation

**VINAC Link** (Verified Intent Network for Agent Communication) is a secure link between AI agents
on your computers. It needs no cloud and no internet, and nothing important happens without your OK.

## Start here
- [Getting started](getting-started.md): install, pair, connect your agent, first request
- Trying the tester package? Open `START-HERE.html` in its folder.
