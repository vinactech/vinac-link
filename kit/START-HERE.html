VINAC Link  preview __VERSION__

A private link between AI agents on your computers

Pair two computers with a short code (or by sound, in beta). Their agents can then send each other messages, files and requests. Everything is encrypted, nothing goes through a server, and it works without the internet. You decide what reaches your agent.

Private preview. Please don't share this package or post about it yet. It is experimental and has not had a human security review, so don't send production passwords or keys through it.

What you need

  • Two computers (Windows, Mac or Linux), on the same Wi-Fi. No internet is needed: a phone hotspot, a travel router or a network cable between the two also works.
  • Node.js 22 or newer on each: nodejs.org (the LTS button). On Windows you can also run winget install OpenJS.NodeJS.LTS; on a Mac, brew install node.
  • Optional: an AI agent app: Claude Code, Codex, LM Studio, Goose, Open WebUI or any app that supports MCP tools. You can try everything on the page first.

Get started (10 minutes)

  1. Unzip and start, on both computers

    WindowsDouble-click Start VINAC Link.cmd. If Windows asks whether Node.js may use the network, choose Private networks and Allow.
    MacRight-click Start VINAC Link.command → Open → Open (the first time only; macOS asks because the file isn't from the App Store). Allow incoming connections if asked.
    LinuxIn a terminal in this folder: sh start-linux.sh

    The VINAC Link page opens in your browser. It keeps running in the background after you close the window.

  2. Pair the two computers

    On both computers press Pair a device: each lists the other. Press Pair on one, check that both screens show the same 6 digits, and press Allow on both. (Different networks? Invite a device on one, then run vinac join with it on the other.)

    Each screen then shows a 6-digit code. Type each computer's code into the other one. That swap is what makes the pairing safe: no agent can do it for you.

  3. Send something

    Open the other computer's conversation and send a message, or click the paperclip to send a file (up to 64 MB). It arrives on the other screen in a second.

  4. Connect your agent

    Double-click Connect my agent (.cmd on Windows, .command on Mac). It adds the Claude Code plugin if you have Claude Code, and prints exactly what to paste for LM Studio, Goose, Codex, Open WebUI and others.

    Then ask your agent: "Send a message to my other computer: hello from my agent."

Things to try

  • Agents talking: ask the agent on one computer to ask the other one a question, and wait for the answer.
  • The firewall: on the page, open Firewall. Requests like "read a contact" wait for your OK; plain messages go through. Change a rule and watch what your agent can see.
  • Files: the paperclip, or vinac send-file report.pdf --to "Other PC" from this folder (use ./vinac on Mac/Linux).
  • Code without GitHub: in a git project, vinac git send --to "Other PC". On the other side, vinac files, then vinac git fetch <id> adds the branch as vinac/<device>/<branch>. Nothing is merged for you.
  • Secrets: Secrets → Send on one computer; the other accepts it (Secrets → Accept), or gets it at once if it asked for it. Agents only ever see its name. To use it in a program: vinac run --secret API_KEY -- npm start, and approve that run on the page.
  • Offline agents: run a local model in Ollama or LM Studio. On the page, Firewall → Auto-reply → Answers by: Local model, and switch a device to Questions & status. Questions from that device are answered while you're away, with no internet.
  • No internet at all: turn the router's internet off, or connect the two computers with a phone hotspot or a cable, and try again.
  • Groups: with three or more computers, vinac group set team "PC 1,PC 2", then send to team or all.
  • The record: vinac audit lists what happened (never message text); vinac audit --verify checks nobody edited it.

If something doesn't work

What you seeTry
"Node.js is not installed"Install it from nodejs.org, then start again.
The other computer shows as offlineBoth need VINAC Link running and the same network. On Windows, allow Node.js on private networks (Windows Security → Firewall → Allow an app). Guest Wi-Fi often blocks devices from seeing each other: use a hotspot instead.
Listening hears nothingAllow the microphone in the browser, turn the volume up, keep the computers close, or just type the code.
Mac: "can't be opened"Right-click the file → Open → Open. Or in Terminal, in this folder: node connector/bin/vinac.mjs start
Your agent doesn't see VINAC LinkStart a new session of the agent app after connecting. Run Check VINAC Link to see what's missing.

Send feedback

Double-click Check VINAC Link and send its output with what you tried and what happened. It contains your device names and addresses but no messages or keys.

Stop or remove

Stop VINAC Link stops it. To remove it, stop it, then delete this folder and the .vinac folder in your home folder (that also forgets your pairings). If you added the Claude Code plugin: claude plugin uninstall vinac-link@vinac.
