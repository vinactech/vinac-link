# Getting help

- **Docs:** start with the [quick start](docs/getting-started.md) and the
  [troubleshooting guide](docs/guide/troubleshooting.md). `vinac doctor` checks your setup.
- **Questions, bugs and ideas:** open an issue in this repository.
- **Security issues:** please don't open a public issue; see [SECURITY.md](SECURITY.md).
- **Anything else** (teams, partnerships, press): write to **hello@vinac.tech** or use the form on
  [vinac.tech](https://vinac.tech/#contact).
