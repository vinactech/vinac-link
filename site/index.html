How it works

Pair once. Then share safely.

  1. 1

    Pair once

    By sound or a short code. You confirm a 6-digit code on each screen; only a person can finish pairing.

  2. 2

    Share keys and tokens

    They go straight into the other computer's key store. Agents can use them, never see them.

  3. 3

    Send requests your rules check

    Each request says what it wants. Your rules let it through, ask you first, or block it.

Online with cloud agents like Claude Code and Codex, or fully offline with local models in LM Studio, Ollama, Goose or Open WebUI. The link between your computers never needs the internet.

What it does

Trust between your computers, in your hands

Trust that only people can create

Each screen shows its own six digits, and you type them into the other computer. Nobody nearby or on the network can slip in, and an agent can start pairing but can't finish it.

  • By sound, or a typed code when there's no microphone
  • Built on the Noise protocol, a published standard
  • Works on your own network, or across networks with Tailscale

Every request says what it wants. Your rules decide.

Agents don't send each other free-form commands. Each request names its purpose from a fixed list, so your computer can check it before your agent ever sees it. Anything that matters waits for a human: you approve or reject it.

  • AllowThe agent sees it right away: questions, status updates.
  • Ask meWaits for your OK: code reviews, task hand-offs, files.
  • BlockNever reaches the agent: running commands, writing files.

Keys and tokens move between computers, never through the chat

Send an API key or token from one computer to the other. It goes straight into that computer's secure key store. Your agent can use it in a program you approve, but only ever sees its name.

  • Stored by Windows, macOS or Linux's own key store
  • Only accepted while you choose to receive one
  • Each use needs your OK on the VINAC Link page

Files and code, checked on arrival

When agents need to share a file or a git branch, it travels encrypted and is checked on arrival. Your rules decide whether it reaches the agent, and nothing is merged for you.

  • Files up to 64 MB
  • A tamper-evident record of what was shared, never the contents
  • Works with no internet at all

Security first

Our technology, on proven foundations

The pairing, the intent firewall and the way secrets move are our own design. Underneath, every connection uses the Noise protocol, the published cryptography also used by WireGuard and WhatsApp.

Built in

  • End-to-end encryption, with fresh keys for every session
  • No servers in between: we never see your traffic or keys
  • Keys kept in your operating system's own secure key store
  • Human in the loop: only you can pair devices, approve requests or change your rules

Checked

  • Automated tests that attack it: replay, tampering, downgrade, impersonation
  • A tamper-evident record of pairings, approvals and secret use
  • An independent security audit is planned, and its results will be published

FAQ

Questions

Do I need an account or a server?

No. The two computers talk directly over whatever network connects them: Wi-Fi, a hotspot, a cable, or Tailscale. There is no server in between and no sign-up.

Some AI tools can already message their other sessions. Why VINAC Link?

Built-in messaging usually works within one vendor's tools and goes through that vendor's cloud and account. VINAC Link connects agents from any vendor (Claude Code, Codex, OpenClaw and local models) directly between your own computers, with no account or cloud in between, and works fully offline. It also adds what plain messaging leaves out: a firewall that checks every request, keys and tokens agents can use but never see, and a person who approves what matters.

What about A2A and other agent standards?

Standards such as A2A connect companies' cloud services to each other. VINAC Link is for the agents on your own computers, including ones that are never online. We plan to make VINAC Link work with A2A, so the two fit together rather than compete.

Does it work online and offline?

Both. The link between your computers never needs the internet: Wi-Fi without internet, a hotspot or a cable is enough. Cloud agents such as Claude Code, Codex or Cursor need the internet for their own AI model; local models in LM Studio, Ollama, Goose or Open WebUI can run with no internet at all. You only need a connection once, to download VINAC Link, and you can copy the package over on a USB stick instead.

What leaves my computer?

Only what you or your agent send to a device you paired, encrypted for that device. Nothing goes to us. This website sets no cookies and loads no trackers either.

Can an agent approve its own requests?

No. Agents get tools to send and read. Confirming a pairing, approving a request, changing a rule or revealing a secret value only happens on the VINAC Link page, by a person.

Is the sound safe? Can people hear it?

It's a six-second, very high tone that most adults barely hear. It only helps the two computers find each other; the real check is the 6-digit code you confirm on each side, so overhearing the sound isn't enough to pair.

Which agents work with it?

Claude Code, Codex and OpenClaw have their own setup; LM Studio, Goose, Open WebUI, Cursor and any other MCP app use it as a standard MCP server.

Who makes it?

VINAC Link™ is built by Mexley Marketing Inc., a Canadian company, and released as open source under the Apache-2.0 license. VINAC stands for Verified Intent Network for Agent Communication.
