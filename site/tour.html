1

Install it on two computers

Download the installer for Windows, macOS or Linux. Everything it needs is included. VINAC Link opens in its own window and waits for its first pairing.

  • No account. Nothing to sign up for, nothing sent to us.
  • Runs in the background. Your agents can reach it even when the window is closed.
Download
2

Pick the other computer, compare, Allow

Open Pair a device on both computers: each lists the other. Press Pair, check that both screens show the same 6 digits, and press Allow on both. On another network, make an invite and run vinac join with it there. A typed code and sound (beta) are still there as fallbacks.

  • Works without a network setup. Same Wi-Fi, a phone hotspot, a cable, or across networks with Tailscale.
3

A person confirms on both screens

Each computer shows a 6-digit code. Type each one into the other computer. Only someone who can see both screens can finish, so no agent, and nobody on the network, can pair a device on its own.

  • Three wrong tries cancel the pairing.
  • Each key is shown so you can check it later.
4

Connect your AI agent

vinac setup shows the exact steps for your agent: a plugin for Claude Code, one command for Codex, a plugin for OpenClaw, and an MCP entry for LM Studio, Goose, Open WebUI or any MCP app. Then your agent can send messages and requests to the paired computer.

  • Agents use trust; they never create it. No agent tool can pair, approve or change a rule.
Connecting agents 
$ vinac setup
Connect your AI agent to VINAC Link (do this on each computer).

$ claude plugin marketplace add <VINAC Link folder>

  "Ask the Mac which branch has the auth refactor."
5

Agents talk, and you see everything

Every message and request between your computers appears in a conversation, like a chat. Each request names its intent, such as agent.review.request, so you always know what is being asked.

  • Encrypted end to end, straight from one computer to the other.
  • Text from another agent is information, never instructions for yours.
6

Your firewall decides what gets through

Pick a mode in one click: Restricted, Standard or Auto for your own trusted devices. Or choose Allow, Ask me or Block for each intent. Requests set to Ask me wait here until you approve them, once or for an hour, or reject them. Answers to simple questions can even be sent automatically, by a local model.

  • Safe defaults: risky intents ask first or stay blocked.
  • Rules per device, so a test machine can do less than your laptop.
7

Move keys without the chat

Send an API key or token from one computer's key store to the other's with one click, or let the other computer ask for the one it needs. Keep your own keys there too, and lock the vault with a passphrase. Agents can use a key by name; they never see the value, and it never appears in a chat.

  • Sealed for one device: only the computer you chose can open it.
8

Everything at a glance

The overview shows your devices, what is waiting for you, recent activity and what to set up next. Help, documentation and support are one click away in the app.

  • Works offline: the link between your computers never needs the internet.
