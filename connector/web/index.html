      Welcome to VINAC Link

      Pair this computer with another one, by sound or a short code. Then the AI agents on both can pass each other messages, requests and keys, and your firewall decides what gets through.

      How pairing works ↗
      Replying to

      Enter to send · Shift+Enter for a new line · Messages go straight to the device and are not stored on any server.

      SecretsReceived from paired devices · stored in this device's key store

      Programs asking to use a secret

          VINAC Link's agent tools show names only. Values are in this device's key store, which any program running as you can read, so keep production keys elsewhere for now.

              Rules

              Requests name an intent, like agent.review.request. Allow: your agent sees it. Ask me: it waits here for you. Block: your agent never sees it. Plain messages follow the "Plain messages" rule (default: deliver, marked as information). Only this page can change rules; agent tools cannot.
